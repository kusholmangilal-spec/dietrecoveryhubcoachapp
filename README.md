# Diet Recovery Hub — Coach

Flutter app for coaches on the Diet Recovery Hub. The flow is:

Welcome → Coach Registration → Admin Verification → Coach Login → Coach Dashboard

Dashboard modules:

- My Clients
- Pending Meal Reviews
- Diet Plans
- Client Progress
- Reports
- Consultations
- Notifications
- Profile

## Demo login

- Email: `coach@dietrecoveryhub.com`
- Password: `Coach@123`

New coaches can register, wait on the admin verification screen (use **Simulate admin approval** in this prototype), then sign in with the password they created.

## Run

```bash
flutter pub get
flutter run
```

```bash
flutter test
flutter analyze
```
